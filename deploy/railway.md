## Деплой

Сервис подключён к GitHub-репозиторию `ShohruhDev/shohruxdev`, ветка `master`. Каждый push или слияние PR в `master` запускает GitHub Actions (`.github/workflows/ci.yml`: форматирование, unit, typecheck, сборка, интеграционные тесты). Railway ждёт результата (Wait for CI, `checkSuites=true`) и выкладывает коммит только при зелёных проверках. Если проверки упали, на сайте остаётся предыдущая версия.

Ручной деплой без GitHub (только в крайнем случае): `railway up --service web --detach` из папки проекта. Повторить последний деплой: `railway service redeploy --service web`.

Dockerfile собирает Nuxt на Node 24 и запускает отдельный runtime-образ. `railway.json` задаёт проверку `/` и одну реплику.

Railway CLI 5.57.9 сообщает, что Config as Code поддерживается до 1 декабря 2026. Перед этой датой перенести настройки в актуальную Infrastructure as Code командой `railway config migrate`, затем проверить plan/apply; миграцию не применять вслепую к тому и переменным.

## Данные и настройки

- Volume `web-volume`, путь `/data`; `CONTENT_DB=/data/content.sqlite`.
- Одна реплика, SQLite WAL. При обновлениях возможен короткий перерыв из-за подключения тома.
- HOST=0.0.0.0, PORT=3000, домен направлен на порт 3000.
- SITE_URL установлен на адрес Railway и передаётся в Docker build. SITE_INDEXABLE=false: публичный предпросмотр с демонстрационными статьями, не SEO-запуск. После проверки материалов и выбора основного домена поменять адрес/индексацию и пересобрать.
- ADMIN_LOCAL_PREVIEW=false. ADMIN_PASSWORD и ADMIN_SESSION_SECRET сгенерированы отдельно и переданы через stdin, не входят в код или архив. Пароль находится у владельца в отдельном приватном файле.
- TRUST_PROXY=true для размещения за Railway edge proxy.
- CONTENT_AUTOMATION_ENABLED=false. OpenAI API и модель не подключены, расход на генерацию не запускается.
- Локальная база с тестовыми заявками не загружается в образ.

## Обслуживание

Перед изменениями схемы делать согласованный SQLite backup. Резервные копии тома на стороне Railway требуют отдельной настройки; наличие тома само по себе не является резервной копией.

Для редакционного запуска можно выполнить внутри сервиса `node scripts/editorial.mjs seed` и импортировать черновик через редакцию. Это не публикует его автоматически. Демо-статьи видны только при выключенной индексации.

Контроль: RU/UZ, форма, вход в редакцию, Secure/HttpOnly cookie, недоступность редакционных данных без входа и сохранность заявки после перезапуска.
