# Бренд Razrabotka Tashkent

Полные правила — в двух файлах в корне репозитория. Прочитай тот, что нужен под задачу:

- `DESIGN.md` — цвета, шрифт, радиусы, отступы, компоненты, логотип, форматы для соцсетей. Для всего визуального.
- `BRAND.md` — название, голос, запретные слова, узбекский, числа, правила соцсетей. Для всех текстов.

Источники истины выше этих файлов: `app/assets/corporate.css` (стили), `docs/knowledge-base.md` и `shared/*.mjs` (факты). Нашёл расхождение — поправь `DESIGN.md`/`BRAND.md` в той же задаче.

## Коротко, если некогда

**Визуал**
- Белый фон, тёплые серые полосы `#f8f7f5`, один акцент `#2457f5` (светлый `#eaf0ff`, hover `#1a44cf`). Текст `#1f1f1f` / `#3c3c3c` / `#6b6b6b`, линии `#e7e5e1`.
- Montserrat 400–700. h1 — вес 400, h2/h3 — 600, без uppercase и трекинга.
- Карточки radius 24px, кнопки и поля 8px. Кнопка: 50px, 16px/600, без тени.
- Без eyebrow-плашек и бейджей над заголовками, без эмодзи, стрелок-декора, «акций», новых цветов и градиентов.
- Не копировать чужие бренд-ассеты (friflex и др.).
- Соцсети: лента 1080×1350 (поле 72px), stories 1080×1920 (по 250px сверху и снизу без текста).

**Текст**
- «Razrabotka Tashkent» первым; ООО «LEADVEX AI» — только реквизиты.
- Прямо, коротко, фактами; «мы» и «вы»; в конце — один следующий шаг.
- Нельзя: «топ», «№1», «лучшие», «гарантируем результат», «за три дня», скидки, выдуманные цифры и отзывы, эмодзи.
- UZ — только латиница, o‘/g‘ с ‘ (U+2018). Цены: RU «от 2,5 млн сум», UZ «2.5 mln so‘mdan» — только из `shared/pricing.mjs`.
- Владелец: «Шохрух Бурхонов» (RU) / «Shohrux Burxonov» (UZ).

## Проверка перед сдачей

1. Цвета и радиусы — только из `DESIGN.md`; новых значений нет.
2. Нет плашек над заголовками, эмодзи и запретных слов.
3. Все цифры, цены, кейсы и контакты сверены с кодом и базой знаний.
4. UZ-версия есть (где нужна) и написана латиницей.
5. Для сайта — проверено на десктопе и 375px, RU и UZ.
