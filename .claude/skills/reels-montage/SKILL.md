# Монтаж Reels

Владелец снимает на телефон, мы монтируем. Инструмент — `npm run reels` (`scripts/reels.mjs`): ffmpeg + подписи, отрендеренные через satori в стиле сайта. Стиль — `content/video/style.md`, он главнее твоего вкуса.

## Порядок

1. **Исходник.** Видео лежит в `content/video/raw/`. Если владелец прислал в чат — попроси положить туда. Посмотри длительность: `ffprobe -v error -show_entries format=duration -of csv=p=0 <файл>`.
2. **Текст.** Нужен SRT по времени исходника.
   - Автоматически: `npm run reels -- content/video/raw/clip.mov --transcribe` (по умолчанию `--lang ru`; для узбекского `--lang uz`, но whisper знает его хуже — вычитывай внимательно и проверяй латиницу и ‘). Распознаёт whisper.cpp (`brew install whisper-cpp`), модель `~/.local/share/whisper/ggml-large-v3-turbo-q5_0.bin` (или путь в `WHISPER_MODEL`). SRT ляжет рядом: `content/video/raw/clip.srt`.
   - Вычитай SRT: исправь ошибки распознавания, выдели ключевое слово, потом пересобери с `--srt`. Короткие хвосты реплик скрипт сам приклеит к предыдущей.
   - Если модели нет — попроси у владельца текст того, что он говорит, и расставь тайминги по `silencedetect` (паузы в логе = границы фраз).
   - Каждую реплику прогони через скилл `humanizer` и `BRAND.md`: коротко, без эмодзи, ≤ 2 строк. Одно ключевое слово — в `*звёздочки*` (станет акцентным синим).
3. **Заголовок** — 3–5 слов, суть ролика. Без «топ», «лучшие», выдуманных цифр.
4. **Сборка:**
   ```bash
   npm run reels -- content/video/raw/clip.mov --srt content/video/raw/clip.srt --title "Заголовок" \
     --cta "Рассчитать стоимость — razrabotkatashkent.uz" --out 2026-12-17-calculator.mp4
   ```
   `--cta` — плашка по центру на последние 2.5 секунды (UZ: «Narxni hisoblash — razrabotkatashkent.uz»). Другие флаги: `--keep-pauses` (не резать), `--noise -30dB` (шумная комната), `--min-pause 0.8` (резать только длинные паузы).
5. **Проверка.** Вытащи 3 кадра и посмотри глазами: `ffmpeg -ss <t> -i out.mp4 -frames:v 1 frame.png`. Текст не залезает в верхние/нижние 250px, не обрезан, кириллица/латиница без «квадратиков», вырезанные паузы не рубят слова.
6. **Сдача.** Ролик в `content/video/out/`. Публикует владелец вручную (Reels не умеет автопостинг): дай ему подпись к посту RU/UZ, обложку (кадр) и что выбрать из музыки, если нужна. В `docs/social-strategy-*.md` отметь, что ролик готов.

## Чего не делать
- Не ставить сторонние «скиллы монтажа» из GitHub без согласия владельца — только ffmpeg и код этого репозитория.
- Не коммитить видео (они в `.gitignore`).
- Не накладывать музыку из интернета — права.
- Не добавлять в кадр то, чего не было: клиентов, цифры, отзывы.

## Идеи, где это пригодится
- Reels «Считаем сайт на двух языках в калькуляторе» (запись экрана + голос) из декабрьского плана.
- Нарезка длинного видео/созвона владельца на 2–3 коротких ролика: найди по SRT самые сильные 20–40 секунд, смонтируй каждый отдельно (`ffmpeg -ss A -to B -c copy part.mp4`, затем `npm run reels`).
- Короткие видео в stories «За кадром».
