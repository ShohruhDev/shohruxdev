# Web / Mobile Implementation Plan

> For agentic workers: use superpowers:executing-plans inline. Asset generation and final independent review are bounded delegated tasks.

**Goal:** работающий Nuxt-сайт услуг с заявками и очередью публикаций, плюс стратегия запуска.
**Architecture:** Nuxt SSR, SQLite на постоянном диске, публикация через CLI, без внешних побочных действий.
**Tech Stack:** Nuxt 4, Vue 3, TypeScript, node:sqlite, Phosphor, Manrope.
**Spec:** docs/spec.md

## Global Constraints
- Тёмный выбранный макет, русский язык, адаптивность.
- Никаких выдуманных клиентов, контактов, сроков, отзывов.
- Предпросмотр noindex; публикация требует реального домена.
- Нет существующего Git remote: ветки не создаём; правило origin/master применяется при подключении репозитория.

## Review Focus
- Пустые/слишком длинные и вредоносные поля формы.
- Сохранение до ответа успеха; повторные запросы.
- Черновики и будущие статьи не попадают в публичное API/sitemap.
- Одновременный запуск публикации не дублирует материал.
- Мобильное меню, клавиатура, ошибки формы, 404 и HTML без JS.
