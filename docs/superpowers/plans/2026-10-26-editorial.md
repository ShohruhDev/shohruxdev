# Редакция и привлечение клиентов — план реализации

> Execution: superpowers:executing-plans, в текущей сессии. Пользователь уже разрешил приступать.

Цель: собственный журнал с управлением темами, подготовкой статей через ИИ с веб-поиском, проверкой, ежедневным расписанием и источниками заявок.
Архитектура: существующий Nuxt SSR + SQLite; серверная панель /admin; адаптер OpenAI Responses (исследование, затем структурированный черновик); фоновый worker в долгоживущем Node сервере. Автор Burxonov Shohrux. Реальные ключи и бюджет ещё не предоставлены, платные вызовы не выполняем.

- [x] Хранилище: темы, редактирование черновиков, проверки качества, расписание с часовым поясом Asia/Tashkent, история запусков. Тестировать сохранение, отмену расписания при правках, защиту от дублей и параллельных запусков.
- [x] Авторизация и API панели: HttpOnly сессия, пароль из окружения, same-origin изменения, no-store/noindex, лимит входа. Локальный вход только явным флагом, при loopback и выключенной индексации. HTTP тесты: 401, CSRF403, вход, приватность, редактор и публикация.
- [x] Генерация: веб-поиск по первичным источникам, JSON schema, проверка ссылок по реальным результатам, лимит один запуск/день и месячный лимит, отсутствие скрытых повторных запросов. Тесты через подставной HTTP transport без оплаты. Ошибки сохраняются; незавершённые вызовы не публикуют статью.
- [x] Worker: каждую минуту выпуск готовых статей; после 08:00 Ташкента один черновик/день. SQLite атомарно захватывает работу; устаревший запуск помечается ошибкой, без автоматического повторного расхода в тот же день.
- [x] UI: панель тем, редактор с предпросмотром, календарь, запуск/ошибки, заявки по источникам, UTM ссылки. Существующая тёмная стилистика, mobile.
- [x] Открытый журнал: короткий ответ, автор, даты, источники, FAQ, связанные материалы, Article JSON-LD, RSS и sitemap; robots для OAI-SearchBot при публичном запуске. Демо-материалы исключены из публичного индексируемого сайта.
- [x] Проверка: unit, Nuxt typecheck/build, HTTP интеграция, браузер desktop/mobile; документация настройки и стратегия каналов.

Ограничения: не обещать ранжирование/цитирование; не создавать фальшивые кейсы/цены; не публиковать ИИ черновики до проверки; не отправлять материалы во внешние соцсети без отдельного запроса. Источники переходов — измерение заявок, не полная веб-аналитика и не доказательство цитирования.

Проверено: unit13, typecheck, build, admin HTTP и публичный worker/SSR/feed/robots. Живой OpenAI вызов, домен и размещение требуют окружения владельца и не объявляются завершёнными.
