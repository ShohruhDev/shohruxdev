# Русский и узбекский

Запрос владельца: сделать сайт двуязычным. Узбекский на латинице. Русские URL сохраняются, узбекские под /uz. SSR и переключатель на соответствующую страницу; query формы сохраняется. Публичные тексты/услуги/формы/ошибки и примеры журнала переводятся. Закрытая редакция сохраняет русский интерфейс, получает поля перевода статьи и проверку обеих версий.

Статьи: translations.uz в той же записи, общий slug/источники/автор/календарь. Неполный перевод не публикуется, отсутствие перевода означает 404 в /uz, а не русский текст под узбекским URL. hreflang только для существующих вариантов. Генератор готовит обе версии в одном структурированном ответе; редактор проверяет обе. Прежние русские статьи продолжают работать.

Проверки: валидация перевода, сохранение/ревизии; SSR обеих версий, lang/canonical/hreflang, переходы и форма; sitemap/RSS только существующих опубликованных вариантов; desktop/mobile. Внешняя генерация без ключа не запускается.
