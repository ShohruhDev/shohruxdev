# Визуальное направление и движение

Актуальная версия от 26 октября 2026: после уточнения пользователя дизайн изменён по направлению референсов Alfred Lock, YAA и ImpressON. Предыдущая тёмная композиция с демонстрационной панелью не используется.

## Основные решения

Мятное поле первого экрана, бумажный фон остальных страниц, чёрный текст и оранжевые акценты. Большая типографика Unbounded с кириллицей и узбекской латиницей. Первый экран строится вокруг услуг и задачи клиента. По уточнению пользователя крупное имя, приветствие с именем, географические подписи, декоративные теги и повторяющееся авторство убраны. Имя сохраняется в компактном логотипе и авторстве статей. Оригинальная сгенерированная иллюстрация объёмного курсора используется как декоративный объект, а не как пример выполненного клиентского проекта.

Услуги представлены раскрывающимися строками с графическими плакатами. Процесс — тремя плакатами THINK / SHAPE / BUILD, которые накладываются при прокрутке на достаточно высоких настольных экранах. Журнал — редакционным списком со ссылками на статьи. Контактный блок строится на крупной типографике и круглой стрелке.

## Движение и доступность

Последовательное появление букв, вступление и реакция иллюстрации на мышь, вращение декоративного знака, появление разделов и реакции ссылок. Прокрутка остаётся нативной. Анимация не прячет серверный текст при отключённом JavaScript.

На телефоне и низком экране плакаты идут обычным потоком. Настройка уменьшения движения системы имеет приоритет; кнопка паузы сохраняет пользовательский выбор. Наблюдатели, события и кадры анимации очищаются при смене страницы/размонтировании. Анимации основаны на CSS и браузерном Web Animations API, без дополнительной библиотеки.

## Сохранённые функции

Русская и узбекская версии, серверная выдача, SEO-метаданные, страницы услуг и статей, форма заявки, редакция и подготовка публикаций. Публичные страницы используют светлую тему; закрытая редакция сохраняет прежнюю тёмную тему. Реальные кейсы и результаты не выдуманы. Сайт остаётся локальным предпросмотром без индексации.
