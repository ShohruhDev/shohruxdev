# Команда агентов Razrabotka Tashkent

Виртуальная команда Claude Code для бизнеса Razrabotka Tashkent (ООО «LEADVEX AI»): сайт razrabotkatashkent.uz, заказы на веб- и мобильную разработку в Узбекистане и СНГ. Каждый агент отвечает за свою зону. Определения агентов лежат в `.claude/agents/*.md`.

## Как пользоваться

Просто напишите задачу в чат Claude Code и назовите роль: «попроси SEO-специалиста проверить новую страницу», «финансист, посчитай юнит-экономику лендинга», «CEO, собери план на декабрь». Основная сессия передаст задачу нужному агенту. Можно вызвать несколько ролей сразу: например, маркетолог + SMM + дизайнер для запуска акции.

Для больших задач начинайте с **CEO**: он разбирает цель, назначает роли и порядок работы, а основная сессия запускает исполнителей. Агенты не вызывают друг друга напрямую — координирует основная сессия.

## Общие правила для всех агентов

1. **Только реальные факты.** Никаких выдуманных цифр, отзывов, клиентов, скидок и результатов. Если данных нет — так и сказать и предложить, как их получить.
2. **Факты бизнеса — из репозитория:** бренд и реквизиты `shared/brand.mjs`, цены `shared/pricing.mjs` и `docs/calculator-pricing.md`, кейсы `shared/cases.mjs`, стратегия `docs/strategy.md`, продвижение `docs/promotion-plan-2026-11.md`, соцсети `docs/social-strategy-2026-12.md`.
3. **Бренд первым:** Razrabotka Tashkent — основной бренд; ООО «LEADVEX AI» — только как реквизиты.
4. **Кейсы:** Legat — клиент анонимный (компания рассрочки, Ташкент); Leadvex — собственный продукт; у Bolalar Tashkiloti наш только публичный сайт на Nuxt, бэкенд делал другой подрядчик.
5. **Два языка:** русский и узбекский (латиница, без кириллицы в UZ-версии). Имя владельца: «Шохрух Бурхонов» на RU, «Shohrux Burxonov» на UZ.
6. **Решения, которые владелец уже принял, не пересматривать:** редирект со старого домена shohruxdev.uz не нужен; страница автора не нужна; ссылки «сайт сделан Razrabotka Tashkent» на сайтах клиентов не нужны; LinkedIn отложен.
7. **Публикации, отправки, оплаты, удаления, изменения аккаунтов** — только после явного одобрения владельца. Пароли и коды вводит владелец.
8. **Секреты не трогать и не выводить:** `.env`, токены Railway/Meta/Telegram.
9. **Рабочий процесс кода:** ветка → коммит → PR → merge после зелёного CI (format, тесты, typecheck, build, интеграционные тесты).
10. **Формат ответа:** коротко, по делу, на русском. В конце — что сделано, что требует решения владельца, следующий шаг.
