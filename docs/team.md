# Команда агентов Razrabotka Tashkent

Виртуальная команда Claude Code для бизнеса Razrabotka Tashkent (ООО «LEADVEX AI»): сайт razrabotkatashkent.uz, заказы на веб- и мобильную разработку в Узбекистане и СНГ. Каждый агент отвечает за свою зону. Определения агентов лежат в `.claude/agents/*.md`.

## Как пользоваться

Просто напишите задачу в чат Claude Code и назовите роль: «попроси SEO-специалиста проверить новую страницу», «финансист, посчитай юнит-экономику лендинга», «CEO, собери план на декабрь». Основная сессия передаст задачу нужному агенту. Можно вызвать несколько ролей сразу: например, маркетолог + SMM + дизайнер для запуска акции.

Для больших задач начинайте с **CEO**: он разбирает цель, назначает роли и порядок работы, а основная сессия запускает исполнителей. Агенты не вызывают друг друга напрямую — координирует основная сессия.

## Модели агентов

С 16.11.2026 модель задана в `model:` каждого агента в `.claude/agents/`. Логика: дорогая модель решает и проверяет, рабочая пишет.

- **opus** — ceo, business-analyst, legal, finance: стратегия, ТЗ, договоры и деньги, где ошибка дорогая.
- **sonnet** — developer, qa, devops, data-engineer, data-analyst, designer, copywriter, seo, smm, marketer, sales: основной объём работы.
- **haiku** не назначен: поиск по проекту делает встроенный агент Explore.

Если результат роли стабильно слабый — поднимаем модель этой роли, а не всем сразу.

Все факты о бизнесе — услуги, цены, кейсы, каналы, аккаунты, решения CEO, частые вопросы — в [`docs/knowledge-base.md`](knowledge-base.md). Читайте её перед любой задачей. Нашли устаревший факт — исправьте базу в том же PR и запустите `npm run kb` (копия для Telegram-ботов).

## Общие правила для всех агентов

1. **Только реальные факты.** Никаких выдуманных цифр, отзывов, клиентов, скидок и результатов. Если данных нет — так и сказать и предложить, как их получить.
2. **Факты бизнеса — из репозитория:** бренд и реквизиты `shared/brand.mjs`, цены `shared/pricing.mjs` и `docs/calculator-pricing.md`, кейсы `shared/cases.mjs`, стратегия `docs/strategy.md`, продвижение `docs/promotion-plan-2026-11.md`, соцсети `docs/social-strategy-2026-12.md`.
3. **Бренд первым:** Razrabotka Tashkent — основной бренд; ООО «LEADVEX AI» — только как реквизиты.
4. **Кейсы:** Legat — клиент анонимный (компания рассрочки, Ташкент); Leadvex — собственный продукт; у Bolalar Tashkiloti наш только публичный сайт на Nuxt, бэкенд делал другой подрядчик.
5. **Два языка:** русский и узбекский (латиница, без кириллицы в UZ-версии). Имя владельца: «Шохрух Бурхонов» на RU, «Shohrux Burxonov» на UZ.
6. **Решения, которые владелец уже принял, не пересматривать:** редирект со старого домена shohruxdev.uz не нужен; страница автора не нужна; ссылки «сайт сделан Razrabotka Tashkent» на сайтах клиентов не нужны; LinkedIn отложен.
7. **Публикации, отправки, оплаты, удаления, изменения аккаунтов** — только после явного одобрения владельца. Пароли и коды вводит владелец.
8. **Секреты не трогать и не выводить:** `.env`, токены Railway/Meta/Telegram.
9. **Рабочий процесс кода:** ветка → коммит → PR → merge после зелёного CI (format, тесты, typecheck, build, интеграционные тесты).
10. **Кто мёржит.** Незначительные изменения команда мёржит сама после зелёного CI (так решил владелец 16.11.2026). Незначительное — это одновременно:
    - меняются только `docs/` (бэклог, отчёты, планы), тексты статей и постов (`content/`, `shared/social-posts.mjs`, `shared/telegram-posts.mjs` — без флагов одобрения) или опечатки и мелкие правки текста в `app/`;
    - не затронуты `server/`, `scripts/`, `nuxt.config.ts`, `package*.json`, `.github/`, `deploy/`, `Dockerfile`, `shared/pricing.mjs`, `shared/brand.mjs`, политика `/privacy`;
    - не меняются дизайн, логика, цены и юридические тексты;
    - не больше ~150 изменённых строк вне `docs/`.

    Всё остальное ждёт ревью владельца; в описании такого PR пишется «Нужно ревью владельца». Сомнение — не мёржить.
11. **Формат ответа:** коротко, по делу, на русском. В конце — что сделано, что требует решения владельца, следующий шаг.
12. **Скиллы.** У каждой роли есть профильный скилл из открытых библиотек (Anthropic, obra/superpowers, coreyhaines31/marketingskills, alirezarezvani/claude-skills) — источник и лицензия в `.claude/skills/<скилл>/SOURCE.md`. Это методика, а не факты: цены, кейсы, тон, запреты и решения владельца берутся из наших файлов и главнее скилла. В каждом внешнем скилле сверху блок «Применение в Razrabotka Tashkent» — читай его первым; маркетинговые скиллы берут контекст из `.claude/product-marketing.md` (мы не SaaS: конверсия — заявка → созвон → договор). Соседние скиллы, на которые они ссылаются, тоже установлены. Браузерные проверки — Playwright через `uv run --with playwright python …` (скилл `webapp-testing`). Внешние инструменты из скиллов (curl к сторонним API, установка пакетов, Playwright) — только если задача без них не решается; ничего не публикуй и не отправляй.
