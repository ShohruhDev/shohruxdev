# Поиск клиентов

Вкладка «Клиенты» в `/office`. Код: `server/lib/lead-hunt.mjs`, плагин `server/plugins/lead-hunt.ts`, API `/api/admin/prospects`, интерфейс `app/components/OfficeClients.vue`.

## Как работает

1. **Жасур (продажи)** раз в день после 10:00 по Ташкенту ищет компании в Google Places: следующий по кругу запрос «сегмент + район + Ташкент» (12 сегментов × 10 районов). Берёт до `LEAD_HUNT_DAILY` новых компаний. Кнопка «Найти сейчас» запускает поиск сразу, можно выбрать отрасль и район.
2. **Дильноза (бизнес-аналитик)** открывает сайт компании и записывает, чего не хватает: сайта нет / только соцсеть, сайт не открывается, нет мобильной версии, нет HTTPS, давно не обновлялся, нет записи или формы, нет Telegram. Если сайт в порядке — компания пропускается.
3. **Нигора (копирайтер)** пишет первое сообщение: одно наблюдение, одно предложение по прайсу, один следующий шаг. Правила — `BRAND.md`.
4. **Владелец** проверяет текст, при желании правит или просит «На узбекском» / «Переписать», отправляет сам и нажимает «Отправил». Каналы по приоритету:
   - **Telegram** — ссылка с сайта компании (t.me/…) или **Telegram по номеру** (`t.me/+998…`): откроет чат, если номер есть в Telegram и человек не запретил находить себя по номеру. Текст копируется автоматически — вставьте его в чат.
   - **Письмо** — почта с сайта компании: откроется почтовая программа с готовыми темой и текстом.
   - **Instagram** — профиль с сайта, текст копируется для Direct.
   - **Позвонить**, **WhatsApp** — запасные варианты.

   Контакты Дильноза берёт с главной страницы сайта, со страниц Taplink/Linktree и из ссылки, если вместо сайта указан Telegram или Instagram. Если нет ни Telegram, ни почты, карточка пишет «только звонок».
5. **Жасур** готовит касания 2–4 через 3, 4 и 7 дней. После 4 касаний без ответа компания уходит в «Отказ».
6. Ответившие — колонка «Разговор»: «Созвон», «Сделка», «Отказ».

Ничего не отправляется автоматически: массовые холодные рассылки в Telegram и WhatsApp ведут к блокировкам, а контакты — персональные данные (ЗРУ-547). Отказы и пропуски удаляются через 180 дней.

В командный Telegram-чат Жасур пишет коротко: сколько нашёл и сколько сообщений ждут одобрения.

## Настройка (Railway)

| Переменная | Значение |
|---|---|
| `LEAD_HUNT_ENABLED` | `true` — ежедневный поиск по расписанию |
| `LEAD_HUNT_DAILY` | сколько новых компаний в день, 1–20 (по умолчанию 10) |
| `GOOGLE_PLACES_API_KEY` | ключ Google Cloud с включённым **Places API (New)**; ограничьте ключ этим API |

Черновики пишет модель командного чата (`OPENROUTER_API_KEY`, `TEAM_MODEL`); расход видно в Офисе. Без ключа Google можно добавлять компании вручную кнопкой «+ Компания».

Ключ Google: console.cloud.google.com → новый проект → APIs & Services → Library → «Places API (New)» → Enable → Credentials → Create API key → Restrict key → Places API (New). Нужен платёжный аккаунт; у Places API есть бесплатный месячный лимит — один поиск в день укладывается в него с большим запасом (проверьте текущие условия на странице цен Google Maps Platform).
