# Стиль монтажа Reels — Razrabotka Tashkent

Брендбук монтажа. По нему `npm run reels` и агенты собирают ролики одинаково. Источник цветов и шрифта — `DESIGN.md`; при расхождении прав этот файл.

Как дополнять: положи 3–5 чужих роликов, которые нравятся, в `content/video/refs/` и попроси агента `smm`: «Изучи стиль роликов из refs: шрифты, цвета, субтитры, склейки, зумы, темп, графику и звук. Обнови style.md и покажи мне». Копируем приёмы, а не чужие ассеты.

## Формат
- 1080×1920, 30 fps, H.264 + AAC, громкость −14 LUFS.
- Сверху и снизу по 250px без текста (там интерфейс Instagram).
- Длина 20–45 секунд. Первые 2 секунды — суть, без «Всем привет».

## Текст на экране
- Montserrat 600, тёмный `#1f1f1f` на белой плашке, радиус 24px.
- Одно ключевое слово в реплике — акцентом `#2457f5` (в SRT обернуть в `*звёздочки*`).
- Заголовок первые 3 секунды, сверху, 72px. Субтитры снизу, 60px, не больше двух строк.
- Без эмодзи, капслока, восклицаний. UZ — латиница, o‘/g‘ через ‘.

## Монтаж
- Паузы длиннее 0.6 с вырезаются автоматически, дубли — вручную, оставляем последний удачный.
- Склейки — прямые, без переходов-«шторок».
- Запись экрана (калькулятор, сайт, админка) — крупно, курсор виден.

## Звук
- Голос владельца главный. Музыка — только из библиотеки Instagram при публикации (через API её не добавить).
